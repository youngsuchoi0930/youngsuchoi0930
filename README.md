### 🎙️ [ManualGo](https://github.com/youngsuchoi0930/manualgo) · 근거를 제시하는 매뉴얼 음성 도우미 *(개인)*

> 기기를 다루면서 음성으로 질문하면 매뉴얼의 근거 페이지와 함께 답하는 서비스입니다. **담당: 수집·파싱·검색·음성 응답·출처 UI·평가 전 과정.**

`Python` · `FastAPI` · `ChromaDB` · `ONNX Runtime` · `Azure Speech`

- **96종 매뉴얼**을 수집·파싱했습니다. 같은 정답의 질문만 구어체로 바꾼 **200문항**에서 제품 선택 R@1이 **0.815 → 0.495**로 떨어져 평가셋의 표현 편향을 확인했습니다.
- 재작성한 **640문항**을 구성 선택·검증 각 320개로 분리하고 검색 경로를 조정해, **홀드아웃 320문항 R@5 0.878**을 확인했습니다.
- 로컬 ONNX 임베딩·리랭커를 구성하고 **6GB GPU 메모리 제약**에 맞춰 컴포넌트별 CPU·GPU 실행 장치를 분리했습니다.
- 구어체 질문은 재작성한 평가 자료입니다. 200문항 표현 변경 실험과 320문항 홀드아웃은 별도 평가이며 실제 사용자 이용 데이터는 아닙니다.
